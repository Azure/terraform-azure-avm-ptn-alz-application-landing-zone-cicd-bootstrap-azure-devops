# Example Module - Bicep

> **Note:** This is sample code intended to be seeded into the repositories created by this module. It is not a standalone Terraform module and should not be used directly. It serves as a starting point that users can customize for their own Bicep deployments.

This example Bicep configuration deploys a simple set of Azure resources (virtual network, network interface, and virtual machine) to demonstrate the CI/CD pipeline structure with deployment stacks.
